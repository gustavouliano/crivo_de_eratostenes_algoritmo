# Sequential, Concurrent and Parallel Sieve of Eratosthenes

Performance analysis of the Sieve of Eratosthenes algorithm implemented using sequential, concurrent and parallel programming approaches. The project compares execution time, speedup and efficiency across different problem sizes using Java and C++.

## 📊 Performance Evaluation

The project compares three execution models:

- Sequential Programming
- Concurrent Programming (Java Threads)
- Parallel Programming (OpenMP)

Performance was evaluated by measuring:

- Execution time
- Speedup
- Parallel efficiency
- Impact of different thread counts
- Performance across multiple problem sizes

---

## 📈 Key Findings

- Sequential execution performs better for small problem sizes.
- Parallel execution becomes more efficient for large datasets.
- Concurrent execution outperforms the sequential version only for very large inputs.
- Increasing the number of threads improves performance only up to a practical limit, after which overhead reduces efficiency.
